User Guide

How to use this server: view and print maps, use the Fieldmap app, and run the Admin pages. This guide is stored on the server, so it works without the internet.

1. About the server

This server stores maps and serves them to the computers, phones and tablets on its local network. It does not need the internet to do this.

  • View the maps in a browser.
  • Print paper maps and atlases, or save them as PDF files.
  • Check what can be seen, or where a radio can reach, from a point.
  • Use the maps offline in the Fieldmap app on Android phones and tablets.
  • Use the maps in ATAK, WinTAK, iTAK and other map apps.

Two optional features are disabled until the owner enables them: remote access, which lets paired devices use the server over the internet, and location sharing, which shows the devices' locations to each other. See section 9.

In this guide, a device is a phone or tablet with the Fieldmap app, and the local network is the Wi-Fi or wired network the server is on. The glossary explains other terms.

2. Open the pages

  1. Connect your computer or device to the local network.
  2. Open a browser, such as Chrome, Firefox, Edge or Safari.
  3. Type the server's address in the address bar and press Enter.

You are reading this guide on the server, so its address is:

the address in the address bar of this browser

If you don't know the address, ask whoever set up the server. Write it down and bookmark it.

4. Print a map

Open the Print Map tab. The panel beside the map holds the settings, and the blue outline on the map is the sheet. Press ▾ at the top of the panel to fold it away.

Print one sheet

  1. Choose Map Style, Scale, Paper and Orientation.
  2. Drag the blue outline to the area you want, or tap the map to move the sheet there.
  3. Type a Title if you want one.
  4. Choose Quality: Standard (200 dpi), or High (300 dpi) for sharper lines (slower).
  5. Press Print and choose your printer, or press Download PDF to save a file.

Center Sheet Here moves the sheet to the middle of the screen. Fit Map to Sheet zooms the screen to the sheet. Ground Area, Grid and Center describe the sheet.

Print an atlas

An atlas is a set of overlapping sheets with a cover and an index page. In Pages, choose a size such as Atlas 2 × 2. For a ring binder, tick Binder Margin.

CautionUse a laptop or desktop computer for an atlas. The browser draws every sheet itself, and a phone or tablet can run out of memory.

Choose what the map shows

Open Layers to switch parts of the map on or off, such as contour lines or buildings, or to print in black and white. Changes apply on screen and on paper. Show All Layers switches everything back on.

Markers and drawings

  1. Pick a color in Default Color.
  2. Press Add Marker, Add Arrow, Circle, Rectangle or Polygon.
  3. Follow the hint under the buttons. For a polygon, tap each corner, then press Finish Shape.

Name or remove items in the Markers, Arrows and Shapes lists. Clear All removes everything. Units switches between feet and miles or meters and kilometers. Show Measurements puts lengths and areas on the map. Include Legend Page adds a page with the map symbols and a list of your items.

CautionOnly this browser keeps your drawings. Use Export Drawings to save them to a file, and Import Drawings to open the file again, here or on another computer.

Magnetic model

Each sheet shows the angle between true, grid and magnetic north for the print date. When the magnetic model on the server is close to its end date, the panel shows a notice. Press Update Magnetic Model to download a new one. This needs an internet connection on the server.

5. Terrain tools

If the server has elevation data, Print Map has a Terrain section.

  1. Under Analysis, choose Viewshed (what can be seen from a point) or Radio Coverage (where a VHF or UHF radio can probably reach).
  2. Under Mode, choose Area Coverage (everything around one point) or Point-to-Point (a profile between two points).
  3. Press Place and tap the map to set each point. Drag a point to move it.
  4. Set the heights and the Radius: Observer Height (AGL) and Target Height (AGL) for a viewshed; the frequency and Antenna Height A and B for radio.

For radio, open Link Budget and tick Color by Link Margin to color the map by how much signal is to spare. The result prints with the map. Tick Include Profile Page to print the point-to-point profile on its own page.

CautionThe result is an estimate from the shape of the ground only. Trees, buildings and weather usually make it worse. Check on the ground before you rely on it.

6. Use the maps in ATAK and other apps

  1. On the Maps page, press Tile URLs.
  2. Press Copy beside the map style you want.
  3. In the other app, add a custom map source and paste the address. Look for "map source", "custom map", "XYZ" or "URL" in its settings.

The addresses work for devices that reach the server the same way this browser does.

7. The Fieldmap app

Fieldmap is an Android app for phones and tablets. It shows this server's maps and keeps offline areas on the device for use away from the server.

Get the app

  1. Connect the device to the local network.
  2. In the device's browser, open this server and go to Admin, Devices.
  3. Under Android App, press Download App and follow the steps.

No app store or account is needed. If there is no app on the Devices page, the server owner has to add it.

Connect to the server

In the app, press Menu, Server, then Find Server. Or type the Server Address and press Connect. Menu, Map Style changes the style.

Show your location

Press Follow and allow location access when Android asks. The map follows your location with North Up; press again for Heading Up. Move the map with your finger to stop following. Your location stays on the device unless you start location sharing.

Offline areas

  1. Connect to the server on the local network.
  2. Press Menu, Offline Areas, Download Area.
  3. Move and zoom until the area is in the frame. Enter an Area Name and choose a Detail Level (lower is a smaller download with less detail).
  4. Check the size, then press Download. Keep the app open until it finishes.

When the server gets new maps, press Menu, Offline Areas, Update All.

Markers

  • Touch and hold the map for 2 seconds to add a marker. Touch and hold the blue dot to mark your location.
  • Tap a marker to change its Name and Color, or to Move or Delete it.
  • Menu, Markers, Export saves them to a file, which Import Drawings on the Print Map page can open. Import reads a file.

Exit the app

Press Menu, Exit to stop the app completely.

8. Admin: Map Builder

The Admin pages are for whoever runs the server. If an Access Code is set, they ask for it first. Some servers don't have a Map Builder; their owner adds maps another way.

The Map Builder downloads map data once. After that, the maps work without the internet.

  1. Press Admin, Map Builder.
  2. Select Regions. Click a region on the map, such as a state, to select it. Click it again to remove it. You can also use Search Regions.
  3. Select Layers. Each line is one layer of the map. Press ? beside a line to read about it. Terrain Resolution sets how detailed the terrain is.
  4. Storage and Build Time. Check that the build fits on the server.
  5. Build. Read Before You Start, press Start Build, and confirm.
CautionA build replaces the layers you select. If the server has one region and you build a different one, it then has only the new one. Select every region you want to keep.

A build needs the internet the whole time and can take hours or days. You can close the page; the build carries on, and the old maps work until it finishes. If it fails or you press Cancel Build, the maps don't change, and the same build resumes where it stopped. Repeat Last Build fills in the last choices; Reset clears them.

9. Optional: remote access and location sharing

The server and the app work without these features. Both are disabled until you enable them.

  • Remote access lets paired devices use the server over the internet. The Remote Connectivity Method is Port Forwarding (a port on your router) or NetBird VPN, one at a time.
  • Location sharing lets devices see each other's locations and share markers. It also works without remote access, on the local network only.

Enable remote access

  1. Press Admin, Remote Access.
  2. Under Remote Connectivity, press Enable. This also starts pairing mode for 10 minutes.
  3. Under Remote Connectivity Method, keep Port Forwarding.
  4. Read Connectivity Status. It says whether devices can reach the server from the internet. Retry Port Mapping asks the router again.

If the router doesn't open the port by itself, tick Manual Port Forwarding and add the rule the page shows in your router's settings. Enter the Public IP Address, or press Detect, then Save. Generate New Port picks a different port.

To switch it off, press Disable. The router's port is closed and paired devices stay on the list. Auto-disable after 90 days without a remote connection does this by itself.

CautionDisable remote access when nobody needs it. Then nothing outside the local network can reach the server.

Some internet connections, such as Starlink or mobile internet, can't open a port. Connectivity Status then says devices can't connect. Use NetBird VPN instead.

NetBird VPN

NetBird connects the server and the paired devices in a private network over the internet, with no port on the router. You need a NetBird account (NetBird has a free plan) or your own NetBird server. Only the server owner needs the account.

CautionUse a NetBird network that is only for this server. Each paired device becomes a member, and members can reach the other computers in the network.
  1. On a computer with internet, open app.netbird.io and sign up. If it offers to add a computer or install NetBird, close that.
  2. In the NetBird dashboard, press Settings, Setup Keys, Create Key (or Create Setup Key). Name it Fieldmap, switch on Make this key reusable, leave Usage limit empty, clear Expires in so it shows Unlimited, and leave Ephemeral Peers off. Press Create Setup Key and copy the key. NetBird shows it only once.
  3. On the local network, open Admin, Remote Access. With Remote Connectivity enabled, choose NetBird VPN under Remote Connectivity Method. Paste the key into Setup Key, leave Management URL as it is, and press Connect. The first time, the server downloads NetBird, which takes a few minutes.
  4. Devices you pair from now on get what they need when you pair them. Devices paired earlier get it the next time they are on the local network with the app open.
  5. To check, take a paired device off the local network (Wi-Fi off, mobile data on) and open the app. It should show Connected, and Connectivity Status shows that a device connected through NetBird.
CautionKeep the setup key secret. Change the connectivity method only while the devices are on the local network or can get to it: a device that is away when you change it can't connect until it has been on the local network once.

To stop using NetBird, choose Port Forwarding. The server keeps the key. If a device is lost: press Remove beside it on the Devices page, delete it under Peers in the NetBird dashboard, revoke the setup key, create a new one, and enter it with Change Setup Key and Connect. The other devices keep working.

Network Isolation

Several Fieldmap servers can share one NetBird account. Network Isolation gives this server and its devices a segment of their own: devices reach only this server's gateway port, and nothing of other servers, their devices, or other computers in the account. The server makes two groups (fieldmap-server-<id>, fieldmap-devices-<id>), one access policy (fieldmap-<id>) and a setup key for its devices. Nothing is set up on the devices.

  1. In the NetBird dashboard, open Team, Service Users. Create a service user named fieldmap-setup with the role Admin, and an access token for it that expires in 1 day. Copy the token (it starts with nbp_).
  2. On the Remote Access page, in the NetBird VPN card, paste it into NetBird Access Token and press Set Up Network Isolation.
  3. Devices that joined NetBird before are moved into the device group once they have connected through NetBird. Leave the Default policy on, let each of them connect from outside once, then press Repair Network Isolation with a new token.
  4. In the dashboard, open Access Control, Policies. If other computers in the account need the Default policy, give them policies of their own first. Then switch Default off.
  5. Press Check Isolation with a token (the Auditor role is enough). The page should say Verified by policy check.
  6. Revoke the setup key you typed by hand, and delete the token or the service user.
CautionAn Admin token can change your whole NetBird account. The server uses it once and never stores it. Give it a short life and delete it afterward.

Press Check Isolation about once a month and after you change policies. Before the device key expires (after a year), press Replace Device Key; paired devices keep working. A removed device stays a NetBird peer until you delete it under Peers.

With your own NetBird server, create the setup key on its dashboard and enter its address (for example https://netbird.example.com) in Management URL before you press Connect.

Pair a device

  1. Make sure Remote Connectivity is enabled.
  2. Connect the device to the local network and open the Fieldmap app.
  3. On Admin, Devices, under Device Pairing, press Start Pairing.
  4. Within 10 minutes, in the app, press Menu, Server, Pair Device.

The device then shows under Paired Devices. Press Remove to lock it out at once, for example if it is lost. Away from the local network, the app connects through the internet by itself.

Enable location sharing

Press Admin, Devices, then Enable under Location Sharing. Active Devices lists who is sharing. Disable stops it for everyone.

CautionThere is no sign-in. Don't enable location sharing on a network that strangers can join: everyone on the local network can see the shared locations.

Share your location

  1. In the app, press Menu, Location Sharing.
  2. Enter a Display Name. Others see this name.
  3. Press Start Sharing.

Sharing continues in the background and with the screen off. Press Stop Sharing, or Menu, Exit, to stop. To share a marker, tap it and tick Share with All Devices. Every device can then change or delete it.

NoteThe server does not store locations. A device that stops sharing leaves the others' maps after about 2 minutes. Shared markers stay on the server.

10. Care and backup

  • Keep the server on while people use it.
  • Keep it dry and cool, with air around it.
  • Don't cut the power during a build. The build stops and has to be resumed.
  • Keep the server's address and any Access Code on paper, in a safe place.
  • Keep a paper copy of this guide: press Print this guide at the top.
  • Ask whoever set up the server to back up its data folder. It holds the maps, the paired devices and the shared markers.
NoteThe server keeps its maps when it is off. After you switch it on, wait a few minutes for the pages to open.
