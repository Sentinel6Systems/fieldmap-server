Phones

Phones with the Fieldmap app that are paired here can use this box's maps from anywhere, also away from this network. Only paired phones get in, and only the maps.

The box's code

Whoever set up this box gave it a code. It is needed to change anything on this page.

Remote access

From outside

Port forwarding

Then give this box's internet address, as the router's status page shows it (or a name of your own that points to it). Phones learn it when they are paired, and again whenever they are home.

Pair a phone

  1. Connect the phone to this network and open the Fieldmap app.
  2. Press Pair a phone here.
  3. In the app: Menu, Server, Pair this phone, within ten minutes.
