NetBird VPN

NetBird connects devices to the server over the internet without opening a port on the router.

  1. Create a NetBird account and a reusable setup key (see the User Guide).
  2. Enter the setup key below.
  3. Click Connect.

The setup key is stored on the server and not shown again. Only paired devices receive it.

Network Isolation

Gives this server and its devices their own segment in the NetBird account: devices reach only this server's gateway port, and nothing of other servers or other machines in the account.

      Android App

      Fieldmap for Android phones and tablets (), served by this server. No app store or account needed.

      1. Connect the device to the server's local network.
      2. On the device, open this address in the browser:
      3. Tap Download App, then open the downloaded file.
      4. If Android asks, allow installs from the browser (Settings > Allow from this source), then go back.
      5. Tap Install. If Google Play Protect warns, tap Install anyway.
      Download App

      To update, install the new version over the old one. Offline areas and markers are kept.

      No app is installed on the server. To download the latest release, run ./scripts/app.sh fetch on the server. To add an app file, run ./scripts/app.sh add <file.apk>.

      Device Pairing

      Enable remote connectivity first: Remote Access.

      1. Connect the device to the server's local network and open the Fieldmap app.
      2. Click Start Pairing below.
      3. Within 10 minutes, in the app tap Menu > Server > Pair Device.
