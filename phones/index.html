Devices

Android phones and tablets with the Fieldmap app that are paired here can use this box's maps from anywhere, also away from this network. Only paired devices get in, and only to the maps and, when sharing is switched on below, to each other's positions and markers.

The box's code

Whoever set up this box gave it a code. It is needed to change anything on this page.

Get the Fieldmap app

Fieldmap for Android phones and tablets, , straight from this box: no app store, no account.

  1. Connect the device to this box's network. In its browser, open
  2. Press Download the app there, then open the downloaded file.
  3. Android asks whether the browser may install apps: open Settings in that message, switch on Allow from this source, go back and press Install. If Google Play Protect asks about an app it does not know, choose Install anyway.
Download the app

To update the app, download it again here and install it over the old one: saved maps and markers stay.

There is no app on this box yet. Whoever set up the box adds it on the box with ./scripts/app.sh fetch (the newest published release) or ./scripts/app.sh add <file.apk>.

Pair a device

  1. Connect the device to this network and open the Fieldmap app (Get the Fieldmap app, above).
  2. Press Pair a device here.
  3. In the app: Menu, Server, Pair this device, within ten minutes.
