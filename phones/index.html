Remote access

With remote access, the paired devices can use the maps of the box from outside the box's network. Only paired devices can come in. They get the maps, and the shared positions and markers when sharing is on.

Get the Fieldmap app

Fieldmap for Android phones and tablets (). You get it from the box. You do not need an app store or an account.

  1. Connect the device to the box's network.
  2. On the device, open this address in the browser:
  3. Press Download the app.
  4. Open the file that you downloaded.
  5. If Android asks for permission to install apps from the browser, press Settings. Switch on Allow from this source. Go back.
  6. Press Install. If Google Play Protect shows a message, press Install anyway.
Download the app

To update the app, do the same steps again. The app keeps its map areas and markers.

The box has no app yet. To add the newest app, type ./scripts/app.sh fetch on the box. To add an app file, type ./scripts/app.sh add <file.apk>.

Pair a device

To pair a device, switch on remote access first: Admin, Remote access.

  1. Connect the device to the box's network.
  2. Open the Fieldmap app on the device.
  3. Press Pair a device on this page.
  4. In the app, press Menu, Box, Pair this device. Do this in 10 minutes or less.
