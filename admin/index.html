        2 Select Layers
        
  
        Select the map layers to build. Press ? for details about a layer.
        
  
          

  
          
    Advanced Options
    
          
      
          
        
        
        
          Standard uses satellite terrain data with a point about every 30 meters, including trees and buildings. High uses a US bare-earth survey with a point about every 10 meters and shows small features such as stream banks and road cuts, but the terrain layers need about 10 times the storage and build time; outside the United States it has no effect. High + One Very High Area also adds 1-meter data for one area that you select on the map, up to 100 × 100 km (a download of about 50 to 150 GB at the largest size).

Only the hillshade uses the 1-meter data, where it is available; the rest of the area uses 10-meter data.

          4 Build
          
  
          
    
          Before You Start
          
    
            
      
          • A new layer replaces the installed layer. It does not add to it: if the server has Germany and you build France, the server then has only France. To keep both, select both.
            • 
      
          • Layers that you do not select do not change.
            • 
      
          • The current maps work until the build is complete. The server installs all the new maps together at the end. If the build stops early, nothing changes.
            • 
      
          • A build can take hours or days. It needs an internet connection the whole time. You can close this page; the build continues.
